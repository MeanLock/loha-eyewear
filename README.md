# LoHa Eyewear

Chào mừng đến với dự án kinh doanh mắt kính - **LoHa Eyewear**. 

Dự án này là một monorepo bao gồm:

- `backend`: Backend API Server được xây dựng bằng NestJS, sử dụng TypeORM và PostgreSQL.
- `frontend`: Giao diện người dùng cho ứng dụng (hiện đang được thiết lập).

## Cấu trúc thư mục

```text
loha-eyewear/
├── backend/    # Chứa mã nguồn cho NestJS API server
├── frontend/   # Chứa mã nguồn cho ứng dụng Frontend
├── README.md   # File hướng dẫn này
└── .gitignore  # Các file/folder bị loại bỏ khi dùng git
```

## Bắt đầu

### Phía Backend
1. Di chuyển vào thư mục `backend`: 
   ```bash
   cd backend
   ```
2. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```
3. Tạo file `.env` từ `.env.example` và cấu hình các biến môi trường nếu cần thiết.
4. Chạy chế độ phát triển (development):
   ```bash
   npm run start:dev
   ```
